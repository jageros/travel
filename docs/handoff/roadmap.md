# Cedar Trips 接下来做什么

计划维护日期：2026-11-21。以 **2026-10-20 首发**为经营起点；先重新核对 [当前交接](README.md) 中的日期快照。以下是计划，不能写成已经完成。

## 首期美国景点

| 景点 | 首期内容 |
| --- | --- |
| Grand Canyon | 南缘观景与走一段 Rim Trail |
| Yellowstone | Old Faithful 与上间歇泉盆地 |
| Yosemite | 从山谷看花岗岩崖壁与瀑布 |
| Golden Gate Bridge | 南端观景、工程展览和原无车攻略 |
| Statue of Liberty | 自由岛、博物馆与登岛核对 |
| National Mall | 纪念碑与博物馆之间如何选段 |
| Kennedy Space Center | Atlantis、Apollo/Saturn V 和参观范围 |
| Balboa Park | 植物建筑、庭院和博物馆 |

1. Grand Canyon、Yellowstone 与 Yosemite 已发布。定时任务按实时官方来源、真实匹配搜索信号和编辑优先级推进，每个北京时间自然日有合格稿件时发布一至三篇。
2. 队列低于六篇可用待发稿时，单次日常运行最多补三篇。优先覆盖景点较少的州，从 NPS 官方概况和访客资料核实事实，查看并登记真实 Commons 授权照片。
3. 每次补稿单独提交，核对生产与预览构建、CI、Cloudflare、待发路由和 sitemap 排除情况。正式发布后再检查页面、图片、canonical 和 sitemap，取得实际 HTTP 200 后记录上线。
4. 照片许可、证据、动态事实或构建未通过时保留阻塞。现有 Search Console 导入是历史数据，当前仍依赖真实 CSV 获取新观测。

## 多语言上线与维护

1. 首批先开放已通过官方来源门禁的公共语言页面和 Grand Canyon、Yellowstone、Yosemite 三篇样稿。其余文章按照翻译计划补齐，旧金山部分来源不可用的文章继续保留英文入口。
2. 定时任务每轮最多选择四篇已发布英文原文，生成缺失或指纹过期的 11 种语言译文。译文独立校验和提交，不占英文每日一至三篇发布配额。
3. 任何原文正文、Golden Gate 补充信息、事实或照片登记变化都会使对应译文重新排队。动态事实仍由原始登记和有效期控制，译文不能把过期事实写成长期结论。
4. 下一批语言候选为俄语、印尼语、土耳其语、越南语、泰语、波兰语、荷兰语和孟加拉语。扩展前先观察首批语言的翻译积压、构建耗时、来源阻塞和 Search Console 分目录数据。

当前四篇最近发布的英文原文均已拥有 11 种语言译文。后续运行优先处理新发布稿和 sourceDigest 变化稿，再从最早积压的英文文章继续补译。

多语言界面使用右上角下拉选择语言，按钮只显示当前语言名和下拉箭头。后续视觉维护沿用现有菜单、焦点、RTL 和移动端规则。

## 每周：用同口径数据改进内容

- Search Console：读取真实可用日期的收录、曝光、查询词、点击、目标页面和设备/国家。对有持续曝光且答案确有缺口的已有页优先修订；现有 SFO 页面为最早可见信号，但样本不支持激进改题或重复铺页。
- GA4 property 559805493：观察自然搜索落地页、后续浏览、站内导航/搜索和阅读深度。无自然搜索 cohort 或后台 processing 就记未可用/无法评估，不作零需求结论。
- 每周抽查至少一篇已发布攻略；检查事实、来源新鲜度、正文链接和照片许可，轮换高变化项。检查移动性能；实验室数值和真实用户 Core Web Vitals 分别记录。
- 数据导出原件留 ignored artifacts；版本库只保存必要日期/汇总/编辑输入与结论。记录改动前后窗口，不用事件量充当读者数，不混合属性/页面/查询词聚合。
- 通过普通 PR 交付实质改进；按实际成本和收入文件记账，尚未能取得则明确缺失。无新可行动信号时不重复通知权限问题或正常运行。

## 后续阶段与收入

- **第 31–60 天**：优先实际查询词和落地页信号，完善已获曝光的内容，再扩展有独立增量的子问题。第 31 天约为 11 月 19 日，届时重新评估数据，不按日历自动增加发布量。

- 有足够实际样本后一次测试一个广告变量；Page RPM 用广告平台匹配口径页面浏览量，另列每千 session 收入；净收益扣除对应时期实际内容/托管/工具成本。不把 GA 的零收入字段当成广告报表。
